A network you can investigate

Ayasdi combined Mapper, visual exploration and statistical comparison of populations. This Studio implements that workflow with JuliaTDA algorithms and adds persistence, ToMATo and multiparameter filtrations.

Limits of this release

Up to 3,000 rows and 80 geometry variables. Persistence uses up to 300 landmarks for H0/H1 and 80 for H2. Multiparameter analysis uses up to 28 landmarks. Equivalence to proprietary lenses, million-row processing and automatic optimal-model search have not been established.

Differences found in groups explored in the same data are hypotheses. The displayed p- and q-values do not correct this selection bias.

How to read Mapper

A node is a group of similar observations within a lens interval.

An edge indicates shared rows. Visual position depends on the layout.

Groups count each row once. Calculations and data stay on this computer.

Your space for exploration

Shift + click adds to or removes from the selection. Drag a node to reposition it; drag the background to pan.

Use Select area to mark several nodes. The projection below shows the same rows and also supports selection.

Esc clears the selection. F fits the graph. + and − control zoom.

Nodes can also be selected with Tab and Enter. Changing color or layout does not recompute the model.

Save workspace exports data, configurations, groups and models as JSON. Open the file to resume your analysis.

Selection is exploratory. Check metrics, preprocessing, landmarks and notes before interpreting results.
